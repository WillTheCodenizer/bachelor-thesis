📋 PROJEKTÜBERSICHT
────────────────────────────────────────────────────────────────────────────

Dieses Framework analysiert räumliche Kreuzkorrelationen zwischen Fast Radio
Bursts (FRBs) und Galaxien zur Untersuchung möglicher astrophysikalischer
Assoziationen.

💻 TYPISCHER WORKFLOW
────────────────────────────────────────────────────────────────────────────

Step 1: Kataloge generieren/laden
  from src.simulation import create_realistic_mock_catalogs
  frbs, galaxies, random = create_realistic_mock_catalogs(
      n_frbs=150, n_galaxies=8000
  )

Step 2: Kreuzkorrelation berechnen
  from src.correlation import CrossCorrelationAnalyzer
  analyzer = CrossCorrelationAnalyzer(frbs, galaxies, random)
  result = analyzer.compute_correlation_with_bootstrap(n_bootstrap=100)

Step 3: Statistische Tests
  from src.statistics import StatisticalAnalyzer
  sig = StatisticalAnalyzer.correlation_significance_test(
      result['correlation'], result['xi_error_bootstrap'], 
      result['bin_centers']
  )

Step 4: Interpretation
  from src.statistics import ResultInterpreter
  interp = ResultInterpreter.interpret_correlation(sig, ...)
  print(interp)

Step 5: Plots
  from src.plotting import create_all_plots
  create_all_plots(result, frbs, galaxies, random)

🤝 SUPPORT & ERWEITERUNG
────────────────────────────────────────────────────────────────────────────

Häufige Fragen:

Q: Wie ändere ich die maximale Entfernung?
A: In main.py: result_2d = analyzer.compute_2d_correlation(max_sep=60)

Q: Wie verwende ich echte Daten?
A: Laden Sie CSV: loader.load_frb_catalog_from_csv('data/frbs.csv')

Q: Kann ich 3D Analyse machen?
A: Ja, siehe utils.py euclidean_distance_3d() Funktion

Q: Wie speichere ich Ergebnisse?
A: Plots werden automatisch in outputs/ gespeichert
   Kataloge: loader.save_catalog(cat, 'output.csv')

Q: Kann ich Bootstrap-Samples erhöhen?
A: Ja, in main.py: analyzer.compute_correlation_with_bootstrap(n_bootstrap=500)
